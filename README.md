# 北海道 市町村別人口推移 WebGIS(デモ)

`01_仕様/02_北海道市町村人口推移WebGIS_仕様書.md` の仕様に基づくデモアプリ。
北海道179市町村の人口(大正9年/1920年〜令和2年/2020年、国勢調査ベース)を、
現在の市町村境界に組み替えたうえで色分け表示し、年次アニメーションで再生する。

## 使い方(閲覧のみ)

`public/` フォルダがそのまま静的サイト。ビルド不要。ローカルで確認する場合は
適当な静的サーバーで配信する(フロントは `fetch` で `data/*.json` を読むため、
`file://` で直接開くとCORSでブロックされる)。

```bash
cd 02_デモアプリ/02_claude_北海道人口推移webgis/public
npx serve .
# または: npx http-server . -p 5175
```

ブラウザで表示されたURLを開く。GitHub Pages 等にそのまま `public/` の中身を置けば公開できる。

## 画面の見方

- 上部中央に北海道総人口(179市町村計)を表示。数値の下に1920〜2020年の推移カーブと現在地点の
  マーカーがあり、全体のどのあたり(増加期/ピーク付近/減少期)にいるかが一目でわかる。
- 市町村をクリックすると、その市町村自身の推移カーブと現在地点も表示される(スケールは市町村ごと)。
- 再生は`requestAnimationFrame`で毎フレーム年を連続的に進めており、年をまたいでも数値・色・
  カーブ上のマーカーがなめらかに動く(1年単位のカクつきが出ないようにしている)。
- 地図の色は右下のセレクトで3種類切り替えられる。
  - 「人口」: その年の人口(対数目安のスケール)。
  - 「前年比増減」(初期表示): 前年からの増減量。都市部の増加(赤)・地方の減少(青)が対比できる。
  - 「ピーク比(衰退度)」: その市町村自身の過去最大人口を100%とした現在の残存率。都市規模に
    関係なく「どれだけ空洞化したか」を強調する指標で、小さな町でもピークから大きく減っていれば
    危険色になる。2020年時点では札幌都市圏以外の大半が赤系になり、地方の衰退が視覚的にわかる。
- 右側(凡例の下)に「人口減少ワースト」パネルを常時表示。ピーク比だけだと「元は大きかった炭鉱都市」
  ばかりが上位に来てしまい、元々小規模で過疎が進む村が埋もれてしまうため、
  (1) 現在の絶対人口が少ない順の順位 と (2) 直近20年の年平均人口変化率が低い(減少が速い)順の順位
  を合算した複合スコアでワースト15を算出している。年が進んで順位が入れ替わる際はスライドアニメー
  ション、新規ランクインした市町村は一瞬ハイライトされる。
- 市町村は地図クリックまたはランキングのクリックで詳細パネルを開ける。パネルは**複数同時に開ける**
  (差し替えではなく追加)。同じ市町村を再クリックするとトグルで閉じる。各パネルは×でも個別に
  閉じられる。起動時には、2020年時点の複合スコアで特に深刻な市町村(上位3件)の詳細パネルを
  あらかじめ開いた状態にしてあり、そのまま再生するとそれらの町の推移をリアルタイムで追える。
  開いている市町村はランキング側でもハイライトされる。
- 各詳細パネルには、名称・人口・前年比・実測値/推計値の別に加え、ピーク年とピーク比、
  その市町村自身の推移カーブが表示される。デフォルトで開く3件程度なら1画面に収まるよう、
  余白を切り詰めたコンパクトなレイアウトにしてある。パネル内のグラフをクリックすると、
  地図がその市町村へズームし、黄色い枠で数回点滅してどこにあるかを示す
  (複数パネルを開いていると、どの白枠がどのパネルの市町村か分かりにくいための救済策)。
- 再生速度は「おすすめ(緩急自動)」がデフォルト。年代ごとに`ERAS`に設定した速度係数
  (`speedMul`)に応じて自動で緩急を付ける。炭鉱閉山が始まるエネルギー革命期やバブル崩壊
  以降など、じっくり見てほしい(=ランキングの入れ替わりが激しい)年代は遅く、変化の乏しい
  戦前期などは速く進む。固定速度(0.5〜4年/秒)も選択できる。
- 濃いグレーの地域(道東の一部)は北方領土関連区域。現在も日本の行政が及んでおらず
  国勢調査人口が存在しないため、データなし領域として区別している。
- 主要20市町のみ地図上に常時ラベルを表示。それ以外はクリックで確認する。

## データとその作り方(`data-pipeline/`)

`data-pipeline/scripts/` に、生データから `public/data/` の3ファイル
(`municipalities.geojson`, `no_data_area.geojson`, `population.json`, `label_points.geojson`)
を生成するNode.jsスクリプト一式がある。再生成する場合は以下の順で実行する。

```bash
cd data-pipeline
npm install
node scripts/prepare_boundaries.js   # 境界データの前処理(札幌区統合・北方領土分離)
npx mapshaper output/prepped_municipalities.geojson -dissolve2 code copy-fields=name -simplify 10% keep-shapes -o output/municipalities.geojson format=geojson precision=0.0001
npx mapshaper output/prepped_no_data_area.geojson -dissolve2 code copy-fields=name -simplify 10% keep-shapes -o output/no_data_area.geojson format=geojson precision=0.0001
node scripts/parse_population.js     # 人口Excelの解析
node scripts/build_dataset.js        # 突合・年次補間・最終JSON生成
```

生データ(`raw/`)は同梱していない(サイズが大きいため)。以下から取得する。

- 境界: 国土交通省 国土数値情報 行政区域データ(N03、2024年) `https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2024/N03-20240101_01_GML.zip`
- 人口: 北海道庁 統計課「男女別人口・世帯数」 `https://www.pref.hokkaido.lg.jp/fs/6/1/5/5/9/3/0/_/danjobetu.xls`

### データ処理の要点

- **境界は現在(2024年)の179市町村に統一**。札幌市の10区は1つの「札幌市」に結合。
- **人口は国勢調査年(大正9年・大正14年・昭和5年…令和2年の21時点、昭和20年は未実施のため欠落)が観測値**、
  それ以外の年は前後の観測値の線形補間値。
- 北海道庁の原資料には「平成23年4月1日現在の地名」という列があり、**合併前の旧市町村が現在の
  どの市町村に相当するかを国が既に整理済み**だった。これを使って集約したため、当初仕様で最大の
  難所と想定していた「合併対応表の自作」は、大部分は不要だった(北方領土・千島列島関連の一部の
  行だけ手当てが必要だった)。
- 一部の市町村(赤平市・真狩村など22町村)は1920年時点でまだ独立した自治体として分立しておらず、
  その市町村の観測開始年より前は「データなし」として扱っている(地図上は濃いグレー)。

## 既知の限度(仕様書の「残っている確認事項」より)

- 境界は現在のものに統一しており、当時の市町村境界そのものの再現はしていない。
- 色スケールは指数的な間隔の8段階に対する線形補間で、対数スケールの近似として扱っている。
- 開始年は1920年(大正9年、国勢調査開始年)。それより古い「北海道庁統計書」(明治19年/1886年〜)
  「北海道戸口表」(明治20年〜大正6年/1887〜1917年)も存在は確認したが、国立国会図書館デジタル
  コレクションのスキャン画像のみで、danjobetu.xlsにあったような現市町村への対応表が無く、明治期の
  合併前の町村を現179市町村へ対応付ける作業を自前で行う必要があるため、今回は対象外とした。
